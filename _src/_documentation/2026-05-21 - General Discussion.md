# Family Archive - General Discussion

This is just to get the conversation started on this project. I would like to get an idea of what technologies (e.g. programming languages, platforms, technologies) this idea would require.

## Project Background

I have an ExFAT formatted hard drive that contains thousands of media files (e.g. jpg, mov, aif, etc.) and documents (e.g. pdf, txt, doc, etc.) involving my familiy history. The combination of directory and file names provide a great deal of information about the content of the files, however, I would like to create something that could allow visitors to browse the content through a browser window or even a stand alone app.

## Project Requirements and Wants

Whatever we build should adhere to the following requirements:
- No internet connection required: All functionality, dependencieds and data storage is contained on the hard drive
- The app that's built will live in its own directory in the root of the project
