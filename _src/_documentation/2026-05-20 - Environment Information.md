# Environment Information

This document is to inform Claude what's contained in each directory.

## Directories

Below is a description of what you'll find in each of the directories in this project.

- **__app/**: Contains an old, PHP-based project that was the first attempt at what we're going to try to build here. There is a file at `__app/CLAUDE.md` that describes the architecture of this old project.
  - NOTE: The database that this app works with is managed by MAMP Pro.
- **__development/**: This directory will mostly contain the discussions the developer has with Claude while working on the project.
- **__To File/**: The maintenance of the actual content in this archive (images, videos, audio files, and other documents) is a manual one. This directory contains files that haven't been archived to DVD media, which must be done before they're filed away. It's a temporary housing location.
- **_Development/**: Old projects and support information. Not important.
- **_Documents/**: Primarily documentation on family members. Stuff besides images, videos or audio files.
- **Collections/**: These are miscellaneous collections of related media. Some of this material could be placed in other locations, but I wanted to keep items that were related to one another in the same place to retain their relationship.
- **Groups/**: Images of groups of individuals. Each sub-directory describes the families that are involved in the photographs contained in the directories.
- **Individuals/**: Images which almost all show a single indivdual.
- **Miscellaneous/**: Images that were accumulated over time but don't really fit anywhere else. Most of them don't focus on people, so they don't fit anywhere else.
- **Photo Albums/**: These are ordered scans from organized, physical photo albums. Like the `Collections/` directories, these photos are kept here to retain the order and relationship of the original photo albums.
- **Slide Sets/**: Scans of actual slides. Again, these are kept here to retain their relationship to one another.
- **Unidentified/**: Images of people that I couldn't identify. I have an idea of many but couldn't be sure so I left them here.
- **Videos/**: Contains video and audio elements
  - **Videos/_Logs/**: Spreadsheets with information on some of the videos
  - **Videos/_Projects/**: Adobe Premiere project files
- **Viewable Packages/**: Compressed selections of the other directories. These were put together for my aunt and uncle so they could have a copy of the relevant media they would care about.
