# Gitignore Creation

Here are directions on what I don't want to be tracked by git.

- Any well-known "junk" files that OSX or Windows creates, for example: .DS_Store
- Image files: jpg, png, jpeg, gif, tif, tiff
- Media files: mov, mp4, m4v, aif, aiff, mp3
- Document files: pdf, doc, docx, xls, xlsx, csv
- The following directories and anything inside of them:
  - __app/
  - __To File/
  - _Development/
  - Viewable Packages/
